# Decisions

## D-000 — One active project

ForgeRL is primary. Helix and AgentWorld remain inactive until the program dependency rule permits activation.

## D-001 — Evidence before architecture

No ForgeRL architecture will be designed until evaluation, baseline, and feasibility spikes provide requirements.

## D-002 — Initial model scale

Evaluate 1B–3B first because local hardware cannot train the stated range and cloud budget is unknown. A 7B run must earn its cost through a decision-relevant scaling hypothesis.
